# VALLIS

VALLIS is a governed liquidity + disclosed-odds minigame platform with
occult/ritual UX — liquidity pools (Dust, Dung, Flesh, BloodMoon,
Obsidian), an Anunnaki Treasury Vault, four minigames (CoinFlip, OMEN,
DicerZ, Monolith), and bounded authority layers (SENTINEL, SCAR, EVE).
Revenue comes from ads (AD'AM).
